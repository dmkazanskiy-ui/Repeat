# Repeat — задачи после /reframe (26.11.2026)

Оценка: S — до часа, M — полдня, L — день и больше. Приоритет — по тому, насколько
меняет пользу приложения для «тренера в кармане» (план → факт → коррекция).

## В работе / сделать

| # | Задача | Зачем | Оценка | Статус |
|---|---|---|---|---|
| 1 | **Точность выполнения плана (compliance %)** — у карточки плана процент: время к цели, пульс в коридоре, доля рабочих подходов силовой. Итог недели/плана «точность 87%», на билете тренировки «План 90%», ИИ видит процент в `get_plan`. | Сейчас только «выполнено / нет» — нельзя понять, что план слишком тяжёлый | S–M | ✅ |
| 2 | **Отмена импорта от ИИ одной кнопкой** — после импорта тост «Отменить», в «ИИ-помощник» список последних импортов с «Отменить»: удаляется ровно то, что импорт добавил. | Human-in-the-loop: ИИ можно доверять, если ошибку легко откатить | M | ✅ |
| 3 | **Идемпотентность `submit_*`** — `idempotencyKey` и защита от одинаковых повторов: тот же документ не создаёт второе «входящее». | Агенты повторяют вызовы при сбоях сети | S | ✅ |
| 4 | **Session RPE 1–10** вместо «легко/средне/тяжело»; нагрузка = RPE × минуты для всех видов, старые записи переводятся (легко=3, средне=5, тяжело=8). | Одна шкала нагрузки для зала, бега и бани; основа ACWR | M | |
| 5 | **Боль и травмы** — отметка «болит: зона + 0–10» в самочувствии и после тренировки; готовность и подсказки учитывают; ИИ видит в `get_context`. | Главный повод менять план, сейчас не фиксируется | M | |
| 6 | **Утренний чек-ин от ИИ (HRV, пульс покоя, сон)** — MCP-инструмент `submit_checkin`: Claude берёт данные из Garmin MCP и кладёт в самочувствие; правило плана «HRV < 50 два дня → пятничный зал на дорожку» срабатывает подсказкой. | HRV-guided training на данных, которые уже есть | M | |
| 7 | **ACWR как подсказка в плане** — показать отношение нагрузки на неделе плана, предупредить, если план заводит выше 1,5 (без запретов: модель спорная). | Ранний сигнал перегруза | S–M | |
| 8 | **RIR у подхода (необязательно)** — «в запасе 0–4»; прогрессия учитывает: RIR ≥ 2 на верхе диапазона → прибавка смелее, RIR 0 → держим. | Autoregulation точнее, чем только по повторам | M–L | |
